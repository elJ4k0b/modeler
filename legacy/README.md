# Legacy-Code

Dieser Ordner enthält ältere Implementierungen, die nicht vom aktuellen Build verwendet werden.

- `viewport-controller/`: früherer, nicht angebundener JavaScript-Entwurf für die Viewport-Steuerung
- `compiled-javascript/`: Sicherung der bisherigen Ausgabe aus `javascript/built/` vor der Strukturänderung

Die aktuelle TypeScript-Kompilierung wird mit `npm run build:javascript` unter
`build/javascript/` erzeugt.
